# Leader Elements in Array (C Program)

## 📌 Description
This program finds all leader elements in an array.

A leader element is an element that is greater than or equal to all elements on its right side.

## 🚀 How It Works
- Traverse each element of the array.
- Compare it with all elements on its right.
- If no greater element is found, it is a leader.
- Print all leader elements.

## 📥 Input Array

```text
16 17 5 3 2 1
```

## 📤 Output

```text
Leader = 17
Leader = 5
Leader = 3
Leader = 2
Leader = 1
```
